# KingBlox - Cloud Phone E-commerce Platform

Platform e-commerce untuk Cloud Phone dengan integrasi Discord Bot.

## Fitur

- Next.js 16 dengan Turbopack
- Firebase Authentication & Firestore
- Discord Bot dengan real-time stock updates
- Payment gateway integration (Duitku)
- Admin Dashboard dengan toast notifications

## Tech Stack

- Next.js 16.1.6
- React 19
- Tailwind CSS
- Radix UI
- Firebase (Client + Admin)
- Discord.js

## Development

```bash
npm install
npm run dev
```

## Discord Bot

Bot akan otomatis berjalan saat `npm run dev` dengan concurrently.
